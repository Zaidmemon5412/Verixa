1. EXECUTIVE SUMMARY & VISION
--------------------------------------------------------------------------------
Verixa is a comprehensive, production-grade real estate decision intelligence 
and verification platform. It solves a major pain point in the property market: 
unreliable property listings, hidden legal disputes, builder delivery delays, 
and artificial price inflation.

By combining automated web scraping, legal title document OCR parsing, machine 
learning valuation models, dynamic builder reliability scoring, and geospatial 
locality analytics, Verixa empowers buyers and investors to make data-driven, 
100% legally confident real estate decisions.

--------------------------------------------------------------------------------
2. CORE FEATURES & CAPABILITIES
--------------------------------------------------------------------------------

1. Property Discovery & Research Engine
   - Advanced searching & dynamic multi-attribute filtering (BHK, price range, 
     locality, property type, transaction type, furnishing status).
   - High-resolution property cards with dynamic Trust Scores, Investment Scores, 
     price breakdown per sq.ft., and verified seller metadata.

2. AI Fair Price & Risk Decision Engine
   - Scikit-learn predictive model estimating true fair market value based on 
     carpet area, floor number, age of construction, locality trends, and amenities.
   - Comprehensive risk scoring analyzing builder delay history and legal verification status.

3. Builder Intelligence & Delay Benchmark Module
   - Dedicated builder profiles featuring delivery track records, active vs. 
     completed project counts, RERA registration verifications, and delay benchmarks.

4. Locality Analytics & Infrastructure Scorecard
   - Interactive locality scorecards evaluating safety ratings, traffic index, 
     commercial development, nearby school/hospital proximity, and price trends.

5. Interactive Geospatial Map Engine
   - Integrated Leaflet / OpenStreetMap visualization mapping properties, radius-based 
     nearby amenities, public transit, and locality boundaries dynamically.

6. Side-by-Side Property Comparison Matrix
   - Multi-property comparison tool comparing specifications, pricing, amenities, 
     legal check status, and investment ratings side-by-side.

7. Legal Verification & OCR Document Auditor
   - Tesseract OCR engine parsing NA-permission certificates, title deeds, and 
     khata documents to detect missing compliance filings automatically.

3. TECHNICAL ARCHITECTURE & COMPONENT BREAKDOWN
--------------------------------------------------------------------------------

1. Frontend Architecture:
   - Framework: React 18 + Vite SPA
   - Styling: Tailwind CSS, custom design tokens, modern dark/light cards
   - Icons & UI Components: Lucide React, Radix UI Slot, Class Variance Authority
   - Data Visualization: Recharts (market trends & price graphs), Leaflet / React-Leaflet
   - State & API: Axios HTTP Client, React Context API, custom hooks

2. Backend API Gateway Architecture:
   - Framework: Python 3.11 + Django 4.x + Django REST Framework (DRF)
   - Database: PostgreSQL (JSON B support, spatial coordinates, custom user models)
   - Authentication: SimpleJWT (JSON Web Tokens) + Custom Account User Model
   - Serialization & OpenAPI: DRF Spectacular (Auto OpenAPI schema generation)

3. Data Ingestion & Machine Learning:
   - Scrapers: Selenium & BeautifulSoup4 automated crawlers collecting market data
   - ML Pipeline: Scikit-learn regression models for price valuation & feature encoding
   - OCR Engine: PyTesseract / Tesseract OCR parsing uploaded PDF/Image legal documents
